# Redesign Implementation Tracker

This tracker maps the redesign contract to the concrete runtime surfaces, artifacts, tests, and checked reviewer bundles that currently back the repo.

It is a synchronized evidence tracker, not a substitute for the live open-work ledger:

- the live `/route` default resolves to `dccs_refc`;
- `legacy` remains baseline-only for ablation and comparison surfaces;
- the checked full-suite and hot-rerun reviewer bundles are the current truth for gate and publishability status;
- public claims remain conditional and scoped through `claim_matrix.md`, `docs/claim_matrix.md`, and `docs/theorem_map.md`.

## Evidence Legend

- `source-present`: the code surface exists in the current tree.
- `test-present`: focused regression coverage exists in the current tree.
- `doc-present`: maintained docs/report surfaces describe the current contract.
- `checked-evidence-green`: the checked reviewer artifacts currently report the family closed on current evidence.
- `checked-evidence-red`: the checked reviewer artifacts currently report the family open, unverified, or still blocked on current evidence.
- `conditional-claim-only`: the public claim remains explicitly conditional rather than universal, even when the implementation surface exists.
